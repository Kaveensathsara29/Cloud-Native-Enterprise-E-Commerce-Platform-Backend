# ⚙️ Cloud-Native Enterprise E-Commerce Platform - Backend

A scalable, secure RESTful API service engineered to handle complex business logic, hybrid authentication workflows, database indexing, and cloud-based file storage.

---

## ✨ Key Features

- 🔐 **Hybrid Authentication & Security** — Implements JWT-based authorization alongside OAuth 2.0 Google Sign-In and secure bcrypt password hashing.
- 📂 **Cloud Asset Management** — Integrated Google Drive API via OAuth 2.0 protocols to automate dynamic image uploads and media retrieval.
- ⚡ **Optimized Database Architecture** — MongoDB schemas structured with custom indexing strategies for high-performance, low-latency queries.
- 🛡️ **Robust Middleware Layer** — Custom middleware handling strict request validation, role-based access control (RBAC), and centralized error handling.

---

## 🛠 Tech Stack

- **Runtime Environment:** Node.js
- **Framework:** Express.js
- **Language:** TypeScript
- **Database:** MongoDB
- **Cloud & Auth Services:** Google OAuth 2.0, Google Drive API, JWT, bcrypt
